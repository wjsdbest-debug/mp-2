# MP2 Pokemon Explorer

This React application retrieves data from the PokéAPI and displays the first twelve Pokemon in a responsive card layout.

## Project structure

- `App.tsx` retrieves API data with React Hooks.
- `PokemonGallery.tsx` receives the data through props and builds the user interface with styled-components.
- Each Pokemon card displays its id, name, image, height, weight, and type.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
